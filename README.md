# Student Placement Prediction System

An MLOps-focused machine learning project for predicting student placement outcomes from academic, skill, and experience data.

## Planned Stack

- Python 3.12
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- Joblib
- MLflow
- Pytest
- HTML, CSS, and vanilla JavaScript
- Docker
